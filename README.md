# UCalgary web design system: tutorials

The tutorials page for designers who build UCalgary pages from the design system's Figma file, and two
plugins for the Figma desktop app: the Page check (ucwc-page-check.zip) and the Page builder (ucwc-page-builder.zip).

This repository holds a built copy only. The page and the plugins are made in the design system's own
repository; a change made here is lost at the next build.
