Build a page in six steps

The short version. The full guide, with the starter page, is on the Build a page (opens in a new tab) page of the Figma file.

  1. Copy the starter page

    On Build a page, select the starter page, copy it, add a page of your own and paste.

  2. Add blocks

    Copy a block from Pick a block (opens in a new tab) and paste it after a block on your page, or drag it in from Assets.

  3. Choose design and text

    Select the block, then pick its design, switch parts on or off and type its text in the right panel. A name ending in (max 60) is a limit.

  4. Add or remove items

    Double-click into the block until an item is selected. Ctrl/Cmd+D adds one; Delete removes it.

  5. Put blocks side by side

    Add Layout/Columns, choose its columns, swap each placeholder for a block and choose its In a region design.

  6. Check and hand over

    Run Plugins → Development → UCWC Page check, fix what it lists, and check again.

Get the Page check plugin

The Page check runs in the Figma desktop app and lists what on your page can’t be built as designed: a block in a column it doesn’t fit, text over its limit, anything drawn by hand. You add it once on each computer.

  1. Download the plugin and unzip it. Keep the folder: Figma reads the plugin from it.
  2. In the Figma desktop app, choose Plugins → Development → Import plugin from manifest…
  3. Pick the file manifest.json in the unzipped folder.
  4. To check a page, open it and choose Plugins → Development → UCWC Page check.
